# Visitas aos Enfermos · CCB Vila Clara

## Conteúdo
- `index.html`: aplicação web inicial.
- `README.md`: este guia.

## Antes de usar
Este pacote é uma versão inicial para conectar ao projeto Supabase criado anteriormente. Ele **não contém chaves** e não está publicado na internet.

1. Abra `index.html` em um editor de texto.
2. Localize `COLOCAR_PROJECT_URL` e `COLOCAR_PUBLISHABLE_KEY`.
3. Substitua pelos valores de **Project URL** e **Publishable key** do projeto Supabase.
4. Não use `service_role` ou `Secret key` no navegador.
5. Rode localmente por um servidor (por exemplo, VS Code Live Server ou `python -m http.server`) e acesse o endereço local.

## Atenção com privacidade
As políticas públicas temporárias configuradas no banco podem expor nomes, telefones, endereços e observações. Use apenas dados fictícios enquanto estiver testando. Antes de produção, remova o acesso anônimo às tabelas e defina uma forma segura de consulta, expondo somente os dados estritamente necessários.

## Estrutura esperada no Supabase
O app espera as tabelas `perfis`, `enfermos` e `visitas` conforme o SQL criado no projeto:
- `perfis`: `id`, `tipo`
- `enfermos`: `id`, `nome`, `telefone`, `endereco`, `numero`, `complemento`, `bairro`, `cidade`, `responsavel`, `observacoes`, `ativo`
- `visitas`: `id`, `enfermo_id`, `data_visita`, `horario`, `visitante`, `status`, `observacoes`

O usuário administrador precisa existir em Authentication e ter `perfis.tipo = 'admin'`.

## Observações
Esta é uma base inicial de aplicação em HTML/JavaScript. Teste com dados fictícios e valide as permissões antes de qualquer uso real.
